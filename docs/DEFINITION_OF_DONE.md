# Definition of Done

A Product Backlog Item is Done only when:

- [ ] All acceptance criteria are met
- [ ] Code is committed on a feature branch and merged to main via a pull request
- [ ] Pull request was reviewed and approved by at least one other team member
- [ ] Unit tests for the new code are written and pass
- [ ] The feature works when integrated with main (app runs locally)
- [ ] No known critical defects remain
- [ ] README or docs updated if setup or usage changed
- [ ] Card moved to Done on the project board
