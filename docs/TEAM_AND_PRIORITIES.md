# Why the top five items come first (Product Owner)

1. PBI-02 Project setup and database schema: Nothing else can be built or integrated until the app skeleton and data model exist. It also lets all four developers work in parallel.
2. PBI-01 Browse restaurants: This is the customer's entry point and gives stakeholders the earliest visible value to react to.
3. PBI-12 Set up automated testing: Our Definition of Done requires passing tests, so the framework must exist before features can be completed.
4. PBI-03 View restaurant menu: A customer cannot order without seeing what is available, and it builds directly on browsing.
5. PBI-04 Add items to an order: This starts the core ordering journey, which is QuickBite's main business value.

The remaining items follow the core customer journey. Search and the past-time defect are lower priority because the main flow works without them.
